Scenario analysis

Shock today’s indicators and re-score with the production model. Sliders span each indicator’s 1st–99th historical percentile.

Each shock moves one indicator while holding the others at today’s values. Indicators are correlated, so isolated shocks can behave unexpectedly. For example, a high Sahm reading combined with calm credit markets has historically marked late-recession or recovery months, so a labor-only shock can lower the 12-month probability. Use the replay or multi-indicator presets for realistic paths.

Methodology & model card

Target

For each month t, the label is 1 if any month in t+1 … t+12 is an NBER recession month (FRED USREC). The forward curve refits the same model for 3–24 month windows.

Validation

Expanding-window walk-forward from 1985, refit every January. Training rows are embargoed 12 months before each test year, so no label that was still unknown at forecast time enters training.

Limitations. Indicators use today’s revised data rather than the vintages available in real time, so the backtest is somewhat optimistic. NBER dates recessions with a lag, and the backtest has only four recessions (1990, 2001, 2008, 2020), so treat the estimates as uncertain. This is a research tool, not investment advice.
